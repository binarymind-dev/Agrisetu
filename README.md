# 🌱 AgriSetu

**Farmer–Buyer Direct Market Linkage Platform** | Smart India Hackathon — Problem Statement SIH 26132

AgriSetu मध्यस्थांना दूर करून शेतकऱ्यांना थेट खरेदीदारांशी जोडतं, त्यांना योग्य बाजारभाव मिळावा आणि AI-आधारित insights द्वारे चांगले निर्णय घेता यावेत यासाठी.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 📈 **AI Price Forecast** | Regression मॉडेल वापरून पुढील ७ दिवसांचा किंमत अंदाज |
| 🎙️ **Voice Search** | मराठीत बोलून पिकाची किंमत विचारता येते (Speech Recognition) |
| 🌦️ **Weather-based Advisory** | Live हवामान डेटावर आधारित पीक व्यवस्थापन सल्ला |
| 🤝 **Direct Buyer Connect** | शेतकरी आणि खरेदीदार यांच्यात थेट व्यवहार, मध्यस्थांशिवाय |
| 🤖 **24x7 Chat Assistant** | शेतकऱ्यांच्या सामान्य प्रश्नांना तात्काळ उत्तर |
| 📊 **Admin Analytics Dashboard** | Listings, orders आणि users चा real-time data आणि charts |
| ⚖️ **Quality Grading** | उत्पादनाच्या गुणवत्तेचं मूल्यांकन करणारी स्वतंत्र सेवा |
| 📱 **SMS/IVR Gateway** | इंटरनेट नसलेल्या शेतकऱ्यांसाठी SMS आधारित सेवा |

---

## 🏗️ Tech Stack

- **Frontend:** React (Vite), React Router, Recharts
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **Forecasting Service:** Python, FastAPI, scikit-learn
- **Quality Grading:** Python
- **SMS/IVR Gateway:** Node.js
- **Deployment:** Docker, Docker Compose
